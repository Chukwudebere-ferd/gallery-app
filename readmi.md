# Camp Gallery App Architecture

## Goal

Build a single codebase that serves:

- 🌐 Web users
- 📱 Android users (native APK)
- 🍎 iPhone users (PWA via Safari → Add to Home Screen)

Backend:
- Python (FastAPI)

Frontend:
- React + TypeScript + CSS
- Vite
- Capacitor (Android only)

# Android

Once the website is complete:

```
npm install @capacitor/core
npm install @capacitor/cli

npx cap init

npx cap add android

npm run build

npx cap sync

npx cap open android
```

Android Studio builds:

- APK
- AAB (Play Store)

# Update Strategy

## Option 1

Bundle the React app inside the APK.

```
React

↓

Build

↓

APK
```

Pros

- Fully offline

Cons

Every UI change requires:

- Build
- Sync
- New APK

---

## Option 2

Android app loads the hosted website.

```
Android App

↓
url
```

Pros

- Deploy website
- Users automatically see UI updates
- No APK rebuild for normal frontend changes

Rebuild only when changing:

- Native plugins
- Permissions
- App icon
- Splash screen
- Native Android code

# Long-Term Vision

```
                    FastAPI Backend
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
        ▼                  ▼                  ▼
    Web Browser      Android APK       iPhone PWA
        │                  │                  │
        └──────────────Shared API─────────────┘
                           │
                           ▼
                  Cloud Storage (4K Images)
                           │
                           ▼
                     PostgreSQL Database
```

The web application is the source of truth.

Android is simply another client consuming the same application.

iPhone users use the exact same web application through PWA.

This architecture minimizes development effort, keeps costs close to zero, and allows future expansion to native iOS if an Apple Developer account and macOS become available.
